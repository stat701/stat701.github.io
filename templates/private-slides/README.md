# Private STA 701S slides

This private repository is for the final PDF slides for one STA 701S talk.
Your talk title and abstract remain public on the course website, but the PDF
you submit here is reviewed privately and is not copied to the public site.

## What to submit

Upload exactly one PDF named with your assigned record ID, for example:

```text
fall-2026-01.pdf
```

Place the PDF at the repository root. Do not create folders, and do not add
PowerPoint, Keynote, HTML, LaTeX, images, source files, code, or unrelated
files. The PDF must be 25 MiB or smaller, have 1 to 200 pages, and contain no
attachments or JavaScript.

## How to submit

1. Accept the GitHub invitation to this private repository using the same
   GitHub account that was registered from your public title-and-abstract pull
   request. If this repository gives a 404 page, contact the instructor; do not
   upload a public PDF as a workaround.
2. Use the branch selector, type `slides`, and select **Create branch: slides
   from main**. Do not work directly on `main`.
3. Select **Add file -> Upload files** and upload the one root-level PDF named
   with your record ID.
4. Commit the upload to your `slides` branch.
5. Select **Compare & pull request**. Confirm that the base branch is this
   repository's `main` branch and the compare branch is `slides`.
6. Complete the private-slide checklist and create the pull request.
7. Wait for the instructor's review. If a revision is needed, replace the PDF
   on the same branch so the existing pull request updates.

Private-slide pull requests run a technical PDF check: the PDF must be
readable, unencrypted, 25 MiB or smaller, 1 to 200 pages, free of attachments
and JavaScript, and renderable. They do not receive an AI review. The
instructor reviews and merges the private pull request manually.
